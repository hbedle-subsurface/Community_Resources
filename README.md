# Find Help in Norman — resource directory

A one-page site for First Congregational Church of Norman, UCC that lets people
pick the kind of help they need and get addresses, hours and tap-to-call phone
numbers. Built from the McFarlin Memorial UMC resource list dated 10/23/2026.

Open it here - https://hbedle-subsurface.github.io/Community_Resources/ 

## Files

| File | What it is |
|---|---|
| `index.html` | The English page: layout, styling, search and filtering |
| `resources.js` | All 194 listings in English. **This is the file you edit to update the list.** |
| `es.html` | The Spanish page (same layout, Spanish text and Spanish search) |
| `resources.es.js` | The 194 listings in Spanish, in the same order as `resources.js` |
| `logo.jpeg` | Church logo shown in the header |
| `resource-list.pdf` | The full 6-page flyer, linked from the footer |


## Keeping the Spanish page in step

The two pages are separate, linked by an English / Español button at the top of each.
When a listing changes in `resources.js`, make the same change in `resources.es.js`
(same position in the list). Phone numbers, websites and emails are copied as they are;
only the names of generic services and the descriptions are translated. The Spanish
page links to the same English PDF.

Spanish page: https://hbedle-subsurface.github.io/Community_Resources/es.html
